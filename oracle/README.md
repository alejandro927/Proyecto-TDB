# Oracle (RutaSur) — instalación y scripts

Motor orquestador del proyecto. Corre en una máquina virtual de Azure.

## Entorno

| Elemento | Valor |
|---|---|
| Nube | Microsoft Azure (Azure for Students), región West US 2 |
| Máquina | Standard_B2als_v2 (2 vCPU, 4 GB RAM), 4 GB de swap |
| Sistema operativo | Oracle Linux 8.10 (imagen oficial de Oracle) |
| Base de datos | Oracle AI Database 26ai Free 23.26.3 |
| CDB / PDB | `FREE` / `FREEPDB1` (las tablas viven en `FREEPDB1`) |
| ORACLE_HOME | `/opt/oracle/product/26ai/dbhomeFree` |
| Gateway | DG4ODBC (incluido en `ORACLE_HOME/bin`) |
| ODBC | unixODBC + MySQL Connector/ODBC 26.10 |

La IP pública, la llave SSH y las contraseñas **no** se guardan en el repositorio.

## Orden de ejecución de los scripts

| Script | Se ejecuta como | Qué hace |
|---|---|---|
| `01_usuarios.sql` | `SYSTEM` en `FREEPDB1` | Crea `RUTASUR` (dueño del esquema) y `REPLICADOR` (replicación) |
| `02_tablas.sql` | `RUTASUR` | Crea `catalogo_pais`, `parametros_replicacion` y las 10 tablas del enunciado |
| `03_datos_prueba.sql` | `RUTASUR` | Carga 195 países, 6 parámetros de replicación y los datos de prueba de las 10 tablas |
| `04_database_link.sql` | `REPLICADOR` | *(pendiente)* ODBC, DG4ODBC y database link hacia MySQL |
| `05_bitacora.sql` | `RUTASUR` | Crea `bitacora_replicacion` y `eventos_aplicados` (misma estructura que en MySQL) |

```bash
export NLS_LANG=AMERICAN_AMERICA.AL32UTF8   # para que las tildes se guarden bien
sqlplus rutasur@localhost:1521/FREEPDB1
SQL> @02_tablas.sql
SQL> @03_datos_prueba.sql
SQL> @05_bitacora.sql
```

## Estrategia de identificadores

Oracle genera IDs **impares** y MySQL **pares**. En Oracle cada PK es:

```sql
GENERATED BY DEFAULT ON NULL AS IDENTITY (START WITH 1 INCREMENT BY 2)
```

`BY DEFAULT ON NULL` asigna un impar solo cuando el INSERT no trae ID; los IDs pares que
llegan replicados desde MySQL se insertan tal cual. Así cada registro tiene el mismo ID en
ambos motores y las llaves foráneas se replican sin traducción.

## Instalación de la máquina (resumen)

```bash
# 1. Swap de 4 GB (la máquina trae 0)
sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# 2. Oracle AI Database 26ai Free (el preinstall se instala como dependencia)
curl -L -o /tmp/oracle-free.rpm https://download.oracle.com/otn-pub/otn_software/db-free/oracle-ai-database-free-26ai-23.26.3-1.el8.x86_64.rpm
sudo dnf -y install /tmp/oracle-free.rpm
sudo /etc/init.d/oracle-free-26ai configure
sudo systemctl enable oracle-free-26ai      # arranque automático

# 3. Variables de entorno (~/.bashrc)
export ORACLE_HOME=/opt/oracle/product/26ai/dbhomeFree
export ORACLE_SID=FREE
export PATH=$ORACLE_HOME/bin:$PATH

# 4. ODBC para el database link hacia MySQL
sudo dnf -y install unixODBC
sudo dnf -y install https://dev.mysql.com/get/mysql84-community-release-el8-1.noarch.rpm
sudo dnf -y install mysql-connector-odbc     # /usr/lib64/libmyodbc26w.so
```

## Notas de SQL*Plus

- Una sentencia no puede tener líneas en blanco por dentro (o se usa `SET SQLBLANKLINES ON`).
- No poner comentarios después del `;` en la misma línea: SQL*Plus une esa sentencia con la siguiente.
